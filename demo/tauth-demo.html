TAuth demo

This page connects the mpr-header web component to a local TAuth service running under Docker Compose. Use Google or password authentication, observe the shared profile state, and manage the current account through the configured forms.

How it works

  1. The frontend is served by gHTTP on port 4443 (HTTP), which proxies the configured /auth/* routes to the local TAuth container.
  2. Auth configuration is loaded from ./config-ui.yaml via the mpr-ui-config.js loader, which applies one validated auth-config contract to the header, user, password-auth, and account-panel elements.
  3. The browser only needs the same-origin auth routes: /auth/nonce, /auth/google, /auth/logout, /auth/session, the configured password endpoints, and the configured account endpoints.
  4. The header component requests /auth/nonce after the user selects Google and exchanges the returned credential via /auth/google.
  5. After a refresh or Apple redirect return, mpr-ui restores the profile through /auth/session before it updates the shell state.
  6. Clicking Log out in the menu invokes /auth/logout and resets the profile snapshot below.
